# Glossary

- **Active offer**: An offer currently marked as available by the system state.
- **Business marker**: A map marker representing a business with at least one active offer.
- **Coverage radius**: The distance range shown in the Offers view distance indicator.
- **Offer**: A promotional item with image, description, tags, and location.
- **Tag**: A keyword associated with an offer and used for search matching.
- **User location**: The current geolocation of the user device, if permission is granted.
- **Walking navigation**: External maps navigation mode that uses walking directions.
